# Juris Prudentia UI Map

## Mobile application

The Expo application now provides a navigable front-end prototype for:

1. Welcome
2. Student sign in
3. Student registration
4. Academic onboarding
5. Home dashboard
6. Library and offline/saved states
7. Course hub with notes, cases, law and discussion tabs
8. Topic reader and quiz
9. Case explorer
10. Case brief
11. Community feed
12. Discussion thread
13. New question form
14. Learning progress
15. Notifications
16. Global search
17. Student profile and preferences

The prototype uses local sample content so navigation and all interface states can be reviewed before API integration.

## Administrative portal

The responsive Next.js portal includes:

- `/login` — administrator sign in
- `/` — operational overview
- `/courses` — curriculum listing
- `/courses/criminal-law-1` — course editor
- `/cases` — cases and statutes library
- `/news` — legal news publishing
- `/community` — reports and moderation
- `/users` — user and role management
- `/reports` — learning and engagement analytics
- `/settings` — platform configuration

## Visual system

- Primary navy: `#0B1930`
- Secondary navy: `#142846`
- Gold accent: `#C5A45D`
- Paper background: `#F4F6F9`
- White content surfaces with soft gray borders
- Green, amber and red reserved for statuses and warnings
- Serif headings communicate legal authority; sans-serif interface text preserves readability
